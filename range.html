Range filter editor

A single-criterion value editor: pick a preset range or switch to manual setup to type a custom From/To. The help (?) explains the metric and the trash icon removes the filter. Dropdown on desktop, compact bottom sheet on touch.

Try: open P/E, pick 25 to 35 — the chip shows P/E 25–35. Re-open and hit Custom to type a range, then Apply — it's saved into the list with its own trash to delete. The header trash clears the whole filter. Expiry starts pre-selected via data-default="monthlies"; the others start empty.
